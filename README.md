Undivided is a mod for Planescape: Torment, Enhanced Edition that allows you to travel with all companions at the same time. 

## Features 
Undivided allows you to freely swap all seven companions between party members and followers. 

A companion in follower mode will: 
* contribute normally to combat and dialogs
* use their default party AI script
* leash to the Nameless One outside of combat if they get too far away
* be unable to die, instead "playing dead" until the end of combat
* **not** gain experience
* **not** be able to use their inventory

If you only want some of these companions to be affected, you can modify `settings.tpa` in the mod directory. You can also tune the "leash" distance for followers, making them run to your position if they get too far away from you outside of combat. 

Be aware that conversion to a follower can sometimes cause a companion to drop items. Check the ground whenever you convert a companion into a follower to make sure you don't lose anything important.
